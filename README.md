# A_PersonalRecords Releases

Public release and static resource repository for the closed-source commercial Obsidian plugin **A_PersonalRecords**.

This repository does not contain the plugin source code. Official plugin releases provide the standard Obsidian runtime files, while separately versioned release assets provide optional node illustrations used by the fourth-section canvas.

## Node illustration resources

The plugin can download the illustration package from GitHub Releases. Users may also download the ZIP manually and copy its PNG files into:

```text
.obsidian/plugins/a-personal-records/assets/node-illustrations/
```

The plugin verifies the resource package and individual PNG files with SHA-256 before activating a downloaded version.
