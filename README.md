# A_PersonalRecords Releases

A_PersonalRecords is a closed-source commercial Obsidian plugin for managing personal records, objects, relationships, bills, usage records, and a visual relationship canvas.

This repository hosts official release files and optional static illustration resources. The plugin source is maintained in a private repository and can be made available to Obsidian Community Directory reviewers for review.

## Licensing and payment

Full access requires a valid license. The plugin connects to the licensing service when activating a license and when a scheduled online verification is required.

## Network access

The plugin may connect to the licensing service, GitHub Releases for optional illustrations, image URLs explicitly supplied by the user for cover downloads, and external links activated by the user. The illustration downloader does not download executable code.

## Node illustration resources

Users may download the optional PNG package from GitHub Releases and copy it into `.obsidian/plugins/a-personal-records/assets/node-illustrations/`. The plugin verifies downloaded resource files with SHA-256.
